idlepack 0.2.0 for Windows x86_64 (built with the GNU toolchain; imports only system DLLs).

1. Put idlepack.exe somewhere permanent, e.g. %LOCALAPPDATA%\idlepack\bin, and add that folder to PATH.
2. Run: idlepack init   (add --min-tokens 150k to set the threshold)
3. Fully quit and restart the Claude and Codex desktop apps.

idlepack status / idlepack gain / idlepack config set minTokens 150k / idlepack uninstall.
